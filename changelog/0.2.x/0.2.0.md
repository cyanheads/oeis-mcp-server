# 0.2.0 — 2026-11-11

## Added

- Publish the OEIS guide at skill://oeis-guide/SKILL.md for candidate verification and partial-result interpretation.

## Changed

- `oeis_get_terms` serves up to 1,000 terms by count ([#21](https://github.com/cyanheads/oeis-mcp-server/issues/21)).
- `oeis_get_terms` can fill a slice from the next b-file part ([#23](https://github.com/cyanheads/oeis-mcp-server/issues/23)). When the optional read cannot establish later terms, the result preserves the partial slice and continuation cursor.
- The desktop bundle retains the published guide and omits development files. The root plugin manifest supports Agent Plugins discovery, and Bun builds use 1.4.4.

## Fixed

- `oeis_get_sequence` renders program language tags literally, including underscores and trailing hashes ([#19](https://github.com/cyanheads/oeis-mcp-server/issues/19)).
- `oeis_list_reference` explains that quoted searches match normalized tokens and points callers to the entry formulas to verify signs and operators ([#22](https://github.com/cyanheads/oeis-mcp-server/issues/22)).

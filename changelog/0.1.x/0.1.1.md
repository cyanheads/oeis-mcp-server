# 0.1.1 — 2026-09-30

## Added

- **`oeis_identify_sequence`** finds entries whose data line holds a run of up to 60 consecutive terms (`_` for an unknown one), 10 per page by relevance, each with `matchStartIndex`; signs are ignored unless `matchSigns` is set ([#4](https://github.com/cyanheads/oeis-mcp-server/issues/4)).
- **`oeis_search_sequences`** runs a query in OEIS syntax (words, quoted phrases, term lists, prefixes such as `keyword:` and `author:`, `|`, leading `-`), sorted by `relevance`, `number`, `created`, or `modified`, with `totalCount` and `effectiveQuery`.
- **`oeis_get_sequence`** returns one entry by A-number with eight sections, comments through cross-references; past 24,000 characters it returns the core fields and a sized outline for `sections` to pick from. Withdrawn, reserved, and recycled entries carry a `notice` ([#2](https://github.com/cyanheads/oeis-mcp-server/issues/2)).
- **`oeis_get_terms`** lists `{ n, value }` terms from the entry's b-file (the first 1 MiB; `bFileCut` flags more), or from its data line when it has none; a slice stops at `limit` or about 100,000 bytes ([#1](https://github.com/cyanheads/oeis-mcp-server/issues/1), [#3](https://github.com/cyanheads/oeis-mcp-server/issues/3)).
- **`oeis_get_cross_refs`** lists the A-numbers an entry's cross-reference lines name (`outgoing`, with each `note`), or the entries that mention it (`incoming`). An outgoing page whose name lookup fails returns its rows `resolved: false` with a retry notice.
- **`oeis_list_reference`** decodes keyword flags, search syntax, and identifier and offset conventions from static tables, with no upstream call.
- **`oeis://sequence/{aNumber}`** serves the `oeis_get_sequence` record as JSON, always whole. Every tool and the resource accept `A000045`, `a000045`, `A45`, `45`, or an oeis.org sequence URL.
- **`OeisService`** paces oeis.org to one request start every 10 seconds, retries within a 50 s per-call deadline, and caches records (24 h, then revalidated), searches (1 h), and b-files (7 days). A backed-up queue or a `429` fails as `pacer_shed` or `upstream_rate_limited` with `retryAfter`.
- **`OEIS_QUEUE_MAX_WAIT_MS`** (default `30000`) caps how long a call waits in the oeis.org queue; it is the only server setting, and no API key is needed.
- **OEIS content terms**: content is CC BY-SA 4.0, and every record and row carries its `https://oeis.org/A######` URL for attribution. Terms are exact decimal strings, and contributor-written text renders as inert quotes and code.

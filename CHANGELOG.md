# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-02

oeis_get_terms reads b-file terms past the first 1 MiB, oeis_get_sequence pages section selections past its response budget, and summary rows carry author, last edit, and legacy IDs.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-30

First published release — six tools and a sequence resource over the OEIS: identify a sequence from a run of terms, search with OEIS query syntax, and read entries, b-file terms, and cross-references through a paced, cached oeis.org client.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
